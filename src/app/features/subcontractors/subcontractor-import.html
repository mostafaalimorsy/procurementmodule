What the file must contain

The first row names the columns. Only code and legal_name are required; any other column may be left out. Columns with other names are ignored.

In an Excel workbook only the first sheet is read, and each cell is imported as the text it holds. Formulas and macros are not accepted: paste values only, and format registration numbers as text so Excel keeps every digit.

Columns the import recognises
Column What it holds
code Required. Your permanent code for the firm. A code already in your directory is skipped, or only completed when you choose to add missing details. Repeat a code on further rows to add more contacts.
legal_name Required. The firm's registered name.
commercial_registration, tax_registration Registration numbers. Spaces and dashes are ignored; each number may belong to one subcontractor only.
country A two-letter ISO country code, for example EG.
trades Your trade codes separated by semicolons, for example HVAC;ELEC. Trades must already exist and be active.
contact_name, contact_email, contact_phone A contact for the firm; the first one is the primary contact.
trading_name, city, notes Optional details, as on the subcontractor form.
